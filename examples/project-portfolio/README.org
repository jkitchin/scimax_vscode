#+TITLE: Example: A Team Portfolio (stress test)

A synthetic research group, for stress-testing project management with a team
working across several projects. The project files are generated by
[[file:../../scripts/gen-stress-portfolio.cjs][scripts/gen-stress-portfolio.cjs]]. Regenerate them rather than editing them by hand.

For a small example to learn the features on, see [[file:../project-management/README.org][the project-management example]].

* What is in it

- [[file:people.org]]: eight people, from a PI with 10 research hours a week to an
  undergraduate. Each has =:NICK:=, =:ROLE:=, =:EMAIL:= and =:CAPACITY:=, and
  some have an =Away= subheading with a date range.
- [[file:resources.org]]: shared instruments, a compute allocation and a room,
  tagged =:resource:=, with =:KIND:= and =:CAPACITY:=. The XRD has a maintenance
  window.
- Six projects, each in its own folder with a =.projectile= marker: =h2=, =co2=,
  =mlpot=, =grant=, =battery= and =course=. =co2= and =battery= are split
  across two files.
- About 350 tasks and 26 milestones, with efforts in every supported unit
  (=2d=, =4h=, =90m=, =0:30=), one or two assignees, =@name= tags, inherited
  project leads, priorities, =SCHEDULED= and =DEADLINE= dates, =:ORDERED:=
  phases and subtasks, clocked time on finished and in-progress work, and
  notes.
- Dependencies inside phases, between phases, and eight across projects (the
  grant renewal waits on three other projects' analyses, for example).
- =:USES:= on tasks that need an instrument, room or the cluster, such as
  =:USES: id:res-xrd 4h=.

=:CAPACITY:=, =:KIND:=, the =Away= headings and =:USES:= are not read by any
tool yet. They are the data the planned resource features need.

[[file:portfolio.json]] summarises the generated portfolio: counts, the
cross-project dependencies, and the deliberate problems below.

* Deliberate problems

The generator plants three mistakes that real projects contain, so the tools
can be checked for how they report them:

- a dependency cycle between two tasks in =battery=;
- a dependency on an id that does not exist, in =co2=;
- two tasks with the same =:ID:= in =h2=.

* Regenerating

Dates are laid out around a start date, so regenerate to bring them back to
the present:

#+begin_src sh
node scripts/gen-stress-portfolio.cjs                       # around today, into this folder
node scripts/gen-stress-portfolio.cjs --start 2026-11-30    # around a fixed date
node scripts/gen-stress-portfolio.cjs /tmp/big --scale 5    # five times the tasks, elsewhere
#+end_src

The output is the same for the same =--seed= (default 42), =--start= and
=--scale=.

To try the command-line tools without adding the portfolio to your own
database, index it into a separate one:

#+begin_src sh
scimax --db /tmp/portfolio.db db scan examples/project-portfolio
cd examples/project-portfolio/co2 && scimax --db /tmp/portfolio.db task who --local
#+end_src
