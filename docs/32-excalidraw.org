* ✅ Overview
CLOSED: [2026-01-18 Sun 08:34]

Scimax VS Code integrates with the [[https://marketplace.visualstudio.com/items?itemName=pomdtr.excalidraw-editor][Excalidraw VS Code extension]] to provide
seamless support for creating and editing diagrams directly from org-mode
documents.

** ✅ Prerequisites
CLOSED: [2026-01-18 Sun 08:34]

Install the Excalidraw extension from the VS Code marketplace:

| Extension ID              | Name               |
|---------------------------+--------------------|
| pomdtr.excalidraw-editor  | Excalidraw Editor  |

You can install it via:
- Command Palette: =Extensions: Install Extensions= → search "Excalidraw"
- Or run: =code --install-extension pomdtr.excalidraw-editor=

* ✅ Supported File Formats
CLOSED: [2026-01-18 Sun 08:35]

Excalidraw supports multiple file formats, all of which work with this integration:

| Extension           | Description                              | Hover Preview |
|---------------------+------------------------------------------+---------------|
| .excalidraw         | Native Excalidraw format (JSON)          | Via exports   |
| .excalidraw.json    | Explicit JSON format                     | Via exports   |
| .excalidraw.svg     | SVG with embedded Excalidraw scene data  | Yes           |
| .excalidraw.png     | PNG with embedded Excalidraw scene data  | Yes           |

*Recommendation:* Use =.excalidraw.svg= or =.excalidraw.png= for best experience:
- These formats show hover previews directly
- They embed the full Excalidraw scene data, so they remain fully editable
- They can be displayed in exports (HTML, LaTeX, Markdown)

* 👀 Hover Preview

When you hover over an Excalidraw link, a tooltip appears showing:

1. *Drawing name* - The filename or link description
2. *Visual preview* - For all Excalidraw file types:
   - =.excalidraw.svg= and =.excalidraw.png= files show the image directly
   - =.excalidraw= and =.excalidraw.json= files show a generated SVG preview
3. *Element count* - Number of shapes in the drawing
4. *Links* - For =.excalidraw= files, each linked shape and the org link
   it follows (see [[*Linking Drawings to Your Notes]])
5. *File information* - Size and last modified date

The hover preview for =.excalidraw= files renders the drawing with:
- Rectangles, ellipses, and diamonds with their colors and fill styles
- Lines and arrows with their arrowheads, dashed and dotted strokes
- Text, including labels inside shapes and on arrows
- Freedraw paths and embedded images

For best results, the extension first looks for companion export files (same name
with =.svg= or =.png= extension). If none exist, it generates a preview from the
JSON data.

* ⚠️ Linking Drawings to Your Notes

Shapes in a drawing can link back into your org notebook: click a box in
the diagram and VS Code jumps to the heading, custom id, file or line it
stands for. This turns a figure into a map of your notes.

** ⚠️ How the links work

Excalidraw keeps one link per element. The Excalidraw editor opens
=http=, =https= and =mailto= links in the browser and relative file paths
in VS Code, but it cannot follow org links such as =notes.org::*Results=.
Scimax gives those links a URI that VS Code routes back to scimax:

#+BEGIN_EXAMPLE
vscode://jkitchin.scimax-vscode/org-link?link=file%3A..%2Fnotes.org%3A%3A*Results
vscode://jkitchin.scimax-vscode/org-link?from=/path/notes.org&link=*Results
#+END_EXAMPLE

Scimax follows the =link= parameter exactly as it would follow the same
link clicked in an org file, so every link type works: =file:= with
=::*heading=, =::#custom-id=, =::42= (line) or =::text= searches, =id:=,
=cite:=, =doi:=, =nb:=, =cmd:= and web links. A relative path is relative
to the =from= file when the URI has one, and otherwise to the drawing.

The first time you click such a link, VS Code may ask whether to let
Scimax open the URI. Allow it once and choose to not be asked again.

** ⚠️ Adding a link by hand

1. Put the cursor on a heading in an org file.
2. Run =Scimax: Copy Heading Link for Excalidraw=
   (=scimax.excalidraw.copyOrgLink=). It copies a link to that heading: an
   =id:= link when the heading has an =ID= property, otherwise a
   =#custom-id= or =*Heading= link to the file.
3. In the Excalidraw editor, select a shape, press =Ctrl+K= (=Cmd+K= on
   macOS) and paste the link.

Clicking the link icon on the shape now opens the heading.

** ⚠️ Building linked drawings from a spec

=scimax excalidraw build= turns a short JSON spec into a drawing. Shapes
take a =label=, arrows connect shapes by id with =from= and =to=, and
=orgLink= adds a link into your notes:

#+BEGIN_SRC json
{"elements": [
  {"id": "data", "type": "rectangle", "x": 0, "y": 0, "label": "Raw data",
   "backgroundColor": "#a5d8ff", "orgLink": "file:../notes.org::#data"},
  {"id": "fit", "type": "ellipse", "x": 280, "y": 0, "label": "Model fit",
   "orgLink": "file:../notes.org::*Model fitting"},
  {"type": "arrow", "from": "data", "to": "fit", "label": "clean"}
]}
#+END_SRC

#+BEGIN_SRC sh
scimax excalidraw build spec.json -o diagrams/pipeline.excalidraw.svg
#+END_SRC

The output is an =.excalidraw.svg=: an image with the scene embedded, so
the Excalidraw editor opens and edits it, and it is still an image for
exports and GitHub. =build= reports any link whose file, heading or custom
id does not exist and exits with status 1. See [[file:30-cli.org::*Excalidraw][Excalidraw in the CLI reference]]
for =render=, =check=, =links= and =json=.

The SVG that =build= writes has clean shapes and system fonts. The
Excalidraw editor redraws it in its hand-drawn style the next time you
save it.

** ⚠️ Asking an AI agent for a diagram

The =scimax-excalidraw= agent skill (installed with =scimax skill install=)
does the whole round trip. Ask, for example:

#+BEGIN_QUOTE
Make a diagram of the analysis pipeline in this file, and link each box to
its section.
#+END_QUOTE

The agent finds the headings, writes and builds the spec, checks every link,
saves the drawing under =diagrams/= and inserts it into your org file:

#+NAME: fig-pipeline

#+END_SRC

* ⚠️ Interactive Figures in HTML Export

A bare link to a drawing (no description), such as
=[[file:diagrams/pipeline.excalidraw.svg]]=, is exported to HTML as an
inline SVG, so its links work in the browser:

| Link in the drawing             | Link in the HTML            |
|---------------------------------+-----------------------------|
| =file:../notes.org::*Results=   | =notes.html#org-results=    |
| =file:../notes.org::#data=      | =notes.html#data=           |
| =id:abc-123=                    | =#abc-123=                  |
| =doi:10.1021/x=                 | =https://doi.org/10.1021/x= |
| =https://...=                   | unchanged                   |
| =cite:=, =cmd:= and other links | removed (the shape stays)   |

Paths are rewritten relative to the exported file, so they work when the
HTML files sit next to their org files, as =scimax export= and publishing
write them. =.excalidraw= and =.excalidraw.json= links are rendered to SVG
the same way. A =#+CAPTION:= or =#+NAME:= above the link makes the
drawing a =<figure>=.

Scripts, event handlers and =javascript:= links in an SVG are removed
before it is inlined. A link with a description, a missing file, or a
drawing over 20 MB is exported as before (an image or a plain link). The
live preview and clipboard export do not inline drawings.

** ✅ Export for Sharing
CLOSED: [2026-01-18 Sun 09:56]

Excalidraw's =.excalidraw.svg= and =.excalidraw.png= formats are ideal because:
- They display correctly in web browsers and image viewers
- They can be embedded in HTML/PDF exports
- They retain full editability (scene data is embedded)

** ✅ Version Control
CLOSED: [2026-01-18 Sun 09:56]

All Excalidraw formats are text-based (JSON or JSON-embedded), making them
suitable for version control with git. The =.excalidraw.svg= format shows
meaningful diffs for the SVG portions.

* ✅ Troubleshooting
CLOSED: [2026-01-18 Sun 08:40]

** ✅ Drawing won't open in visual editor
CLOSED: [2026-01-18 Sun 09:56]

- Ensure the Excalidraw extension is installed: =pomdtr.excalidraw-editor=
- Check that the file extension is correct (=.excalidraw=, =.excalidraw.json=,
  =.excalidraw.svg=, or =.excalidraw.png=)
- Try reloading VS Code window

** ✅ No hover preview appears

- All Excalidraw file types now show hover previews
- For =.excalidraw= files, a simplified SVG is generated from the JSON
- The file must exist on disk for preview to work
- Empty drawings show "Empty drawing" instead of a preview

** ✅ Link not recognized as Excalidraw
CLOSED: [2026-01-18 Sun 08:40]

Ensure the file extension is one of:
- =.excalidraw=
- =.excalidraw.json=
- =.excalidraw.svg=
- =.excalidraw.png=
